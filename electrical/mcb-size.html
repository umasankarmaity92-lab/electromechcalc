How it works

How MCB Size and Curve Type Are Selected

MCB sizing rule of thumb: MCB Rating = Full Load Current × 1.25, rounded up to the nearest standard size — for example, a 12 A FLC needs a 16 A MCB. An MCB (Miniature Circuit Breaker) protects a circuit two ways at once: a thermal element trips on sustained overload (similar in concept to a fuse's continuous-duty rating), and a magnetic element trips near-instantaneously on a genuine short circuit. Correctly sizing an MCB means selecting both the right current rating (thermal protection) and the right curve type (magnetic/instantaneous trip threshold) for the specific load it protects.

Formula used (rating): MCB Rating = Full Load Current × 1.25, rounded up to the next standard MCB size. This mirrors general fuse sizing practice, providing margin above steady operating current for continuous duty.

Curve type selection: curve type describes the magnetic trip threshold as a multiple of rated current — Type B (3-5×), Type C (5-10×), and Type D (10-20×). The right choice depends on how much inrush current your load produces during normal starting: resistive/lighting loads (minimal inrush) use Type B; general and small motor loads (moderate inrush) use Type C; transformers and large motors (high inrush) use Type D.

Worked example: a small motor circuit with 12 A full load current, moderate starting inrush (Type C appropriate). MCB Rating = 12 × 1.25 = 15 A, rounded up to the standard 16 A MCB size. Recommended curve type: C, tripping instantaneously at 5-10×16A = 80-160A for genuine short-circuit protection, while comfortably riding through the motor's normal starting inrush without nuisance tripping.

Why matching curve type to load matters as much as getting the current rating right: a correctly-rated MCB with the wrong curve type still causes problems — a Type B MCB on a motor circuit will likely nuisance-trip on every start (inrush exceeding its low 3-5× instantaneous threshold), while an unnecessarily high curve type (Type D) on a purely resistive circuit provides less sensitive instantaneous fault protection than the load actually needs, potentially slowing fault clearing in a genuine short-circuit event. Getting both the rating and curve type right together is what makes an MCB selection actually appropriate for its specific circuit.

MCB thermal and magnetic protection working together: an MCB's dual protection mechanism means the current rating (the number, like "16A") and the curve type (the letter, like "C") answer two different questions that both need correct answers. The rating answers "how much sustained current can this circuit handle continuously?" via the thermal element, which responds relatively slowly (seconds to minutes) proportional to how far above rated current the actual current runs. The curve type answers "how much brief overcurrent should trip the breaker instantly?" via the magnetic element, which responds in milliseconds once its threshold is exceeded. A load's normal starting inrush needs to stay below the magnetic threshold (so it doesn't trip instantaneously during a normal, expected event) while a genuine fault current needs to exceed it (so protection actually activates quickly when it matters).

Why standard MCB sizes follow a specific numeric series: the standard MCB rating series (6, 10, 16, 20, 25, 32, 40, 50, 63A and so on) follows what's sometimes called a preferred number series, roughly increasing by consistent proportional steps rather than fixed absolute increments — this gives reasonably fine-grained size selection at lower currents (where a small absolute difference matters more proportionally) while avoiding an impractically large number of very close size options at higher currents. Understanding this series helps when a calculated value falls between two standard sizes and you need to select the appropriate next-larger option confidently.

Residual current protection (RCD/RCCB) as a complementary, not alternative, device: MCBs protect against overload and short-circuit current, but don't detect earth leakage (a small current escaping to ground through a fault, potentially through a person) — that's the job of a separate residual current device (RCD or RCCB), which many installations combine with an MCB either as a separate device or a combined RCBO (residual current breaker with overcurrent protection) unit. Selecting an MCB is only one part of a complete circuit protection scheme where earth leakage/shock protection is also a code requirement, which it commonly is for many circuit types.

Summary: use MCB Rating = FLC × 1.25 rounded up to the next standard size, select curve type B for resistive/lighting loads, C for general/small motor loads, and D for high-inrush transformer/large motor loads, pair motor circuits with proper overload protection, and verify the selected MCB's fault interrupting rating against actual available fault current.

Diagnosing nuisance tripping after installation: if an installed MCB trips unexpectedly during normal operation (not during an actual fault), the diagnostic process typically starts by distinguishing between a thermal trip (sustained overload, gradual, the breaker feels warm) and a magnetic trip (instantaneous, associated with a starting event or genuine fault). Thermal nuisance tripping often points to an undersized rating for actual sustained load, while magnetic nuisance tripping during equipment starting often points to an insufficiently high curve type for the load's actual inrush characteristics — correctly identifying which type of trip occurred meaningfully narrows down whether the fix is a larger rating, a higher curve type, or investigating a genuine fault or load problem rather than simply assuming the breaker itself is faulty.

Selecting MCBs as part of a coordinated distribution board design: in a panel with multiple circuits, MCB selection for individual final circuits needs to be coordinated with the panel's main incoming breaker or fuse — ensuring that a fault on one final circuit trips only that circuit's MCB, not the main incoming device, requires checking time-current curve coordination between the two levels, not just confirming each MCB individually meets its own circuit's basic sizing calculation. This coordination becomes increasingly important as panels grow larger and more complex, with multiple levels of protective devices between the main supply and individual final circuits.

Worked Example

Small motor, FLC=12A, moderate inrush: MCB Rating = 12 × 1.25 = 15A → 16A standard size, Type C curve (trips at 80-160A instantaneous).

MCB rating and curve type selection here uses standard general guidelines — for a final design, confirm the exact starting/inrush characteristics of your specific load against the MCB manufacturer's published curve data, and verify the selected MCB's rating and curve type against the applicable electrical code and any downstream protection coordination requirements. Combine with a residual current device (RCD/RCCB) or use a combined RCBO where earth leakage protection is also required, and have the final panel design reviewed by a qualified electrical engineer.

MCB Trip Curve Types and Their Applications

Curve Instantaneous Band Defined In Typical Application
Type Z2–3×IEC 60947-2Semiconductor and measuring circuits, sensitive electronic equipment
Type A2–3×Manufacturer rangeSemiconductor protection. Not part of the IEC 60898-1 household set and not widely stocked — check availability before specifying
Type B3–5×IEC 60898-1Lighting, heating and other resistive loads; most domestic final circuits
Type C5–10×IEC 60898-1Mixed commercial loads, small motors, air conditioning, fluorescent and LED banks
Type K8–12×IEC 60947-2Industrial motor and transformer circuits where a tighter band than Type D is wanted
Type D10–20×IEC 60898-1Transformers, large motors, welding sets and other heavy-inrush equipment

These curve type definitions follow IEC 60898, widely referenced internationally including in Indian electrical practice. The instantaneous trip range is what distinguishes a curve type from another of the same current rating — two 16A MCBs, one Type B and one Type C, have the identical thermal (sustained overload) rating but respond very differently to a brief high-current event.

Two points are worth separating, because they are routinely blurred together in curve-type lists. B, C and D are defined in IEC 60898-1, the standard for household and similar circuit breakers — these are the three you will find in any wholesaler. K and Z belong to industrial breakers built to IEC 60947-2, and A appears only in some manufacturers’ semiconductor-protection ranges. Listing all six as if they were interchangeable options on a shelf leads people to specify a curve their supplier does not carry.

The second point is that the bands overlap. A fault at eleven times rated current sits inside the instantaneous region of Type C, Type K and Type D simultaneously — what separates them is behaviour at the lower end, where a Type B has already tripped instantly and a Type D is still waiting on its thermal element. Choosing a curve is choosing how much brief inrush to ignore, not choosing how fast the breaker is.

That has a safety consequence worth stating plainly: a higher curve raises the current needed for an instantaneous trip, so on a long circuit with high loop impedance a Type D may not reach its magnetic threshold during an earth fault at all, and disconnection then falls to the much slower thermal element. Where a curve is raised to stop nuisance tripping, the earth fault loop impedance should be re-checked against the disconnection time the local wiring rules require.

Pole Configuration

MCB Poles: SP, SP+N, DP, TP, TPN and 4P

The pole count answers a different question from the rating and the curve. Rating asks how much current the breaker carries, curve asks how much inrush it tolerates — poles ask which conductors actually get disconnected when it opens. A 16 A Type C behaves identically as a single-pole or a four-pole device; only the isolation changes.

Configuration Conductors Switched Where It Is Used
SP (1P)Line onlyDomestic final circuits — lighting, socket circuits, fans
SP+N (1P+N)Line + neutralSame duty as SP where the neutral must also be isolated, in one module width
DP (2P)Line + neutralHeavier single-phase appliances, water heaters, and wherever supply polarity is not guaranteed
TP (3P)Three phasesThree-phase loads with no neutral — most three-phase motors
TPN (3P+N)Three phases; neutral on a solid link, not switchedThree-phase distribution boards feeding single-phase circuits from a common neutral
4PThree phases + neutralWhere the neutral itself must be broken — generator changeover, some TT arrangements

TPN and 4P are not the same thing

This is the distinction most pole-count lists get wrong by lumping them together. In a TPN device the neutral passes through a solid link: it is brought into the breaker for convenience of wiring, but it is not disconnected when the breaker trips or is switched off. A 4P device has a genuine fourth switched pole. If your reason for wanting the neutral in the breaker is isolation — working safely on the circuit, or separating a generator neutral — a TPN will not do it.

Where a neutral is switched, the order matters: it must not be disconnected before the line conductors, or re-connected after them. Devices designed for the job handle this internally; improvising one by wiring a neutral through a spare pole of an ordinary breaker does not.

Poles do not change the sizing

Nothing in the rating calculation depends on the pole count. Choose the rating from the load current, the curve from the inrush, and the poles from the isolation the installation needs — three independent decisions that happen to be ordered on the same product code.

Common Mistakes

Common Mistakes When Sizing an MCB

1. Using Type B for a motor circuit. Type B's low instantaneous trip threshold (3-5×) is easily exceeded by normal motor starting inrush, causing nuisance tripping on every start — motor circuits generally need Type C or D depending on their specific inrush characteristics.

2. Defaulting to Type D "to be safe" for every circuit. A higher curve type means less sensitive instantaneous fault protection — using Type D where Type B or C would be appropriate can slow genuine fault clearing without providing any real benefit for a load that doesn't actually need that much inrush tolerance.

3. Relying on MCB sizing alone for motor overload protection. Like fuses, MCBs sized to tolerate motor starting current are generally too insensitive for genuine sustained overload protection — pair motor circuits with a properly sized overload relay or use a motor circuit breaker/protector with dedicated adjustable overload protection.

4. Rounding the calculated rating down to a "close enough" standard size. Always round up to the next standard MCB size at or above the calculated value — rounding down undersizes the MCB below its calculated requirement.

5. Sizing an MCB above the protected cable's ampacity for a general circuit. The MCB should generally trip before the cable itself is damaged by overcurrent — verify the selected MCB rating doesn't exceed the protected cable's safe ampacity, except where a specific, code-recognized exception applies.

6. Not verifying the MCB's fault interrupting rating against actual available fault current. Current rating and curve type address normal operation and instantaneous trip threshold, but the MCB also needs an adequate fault interrupting (breaking) capacity rating for the actual available fault current at its installation point \u2014 a separate, equally important check beyond rating and curve type alone.

7. Ignoring specialized curve types when standard B/C/D don't match unusual equipment characteristics. Some specific loads may warrant a manufacturer-recommended specialized curve type beyond the standard three — check equipment-specific recommendations rather than forcing an unusual load into the closest standard curve type by default.

8. Not distinguishing thermal versus magnetic nuisance tripping when diagnosing an installed circuit. These point to different root causes (rating too low vs curve type too low) and therefore different fixes — correctly identifying which type of trip is occurring saves time and avoids an incorrect fix that doesn't address the actual problem.

FAQ

Frequently Asked Questions

What is the formula for MCB sizing? +

MCB Rating = Full Load Current × 1.25, then rounded up to the next standard MCB size. This 125% factor provides margin above steady operating current for continuous-duty circuits, similar to general fuse sizing practice.

What do MCB curve types B, C, and D mean? +

Curve type describes the MCB's magnetic (instantaneous) trip threshold as a multiple of its rated current — Type B trips instantaneously at 3-5× rated current, Type C at 5-10×, and Type D at 10-20×. A higher curve type tolerates a larger, brief inrush current without instantaneous tripping, which is why the right curve type depends on how much inrush current your specific load produces during normal starting.

Which curve type should I use for general lighting and resistive loads? +

Type B is standard for general lighting, heating, and resistive loads, which have minimal or no significant inrush current beyond their steady operating current — Type B's lower instantaneous trip threshold (3-5×) still provides fast fault clearing for these low-inrush loads without being unnecessarily insensitive.

Which curve type should I use for a motor circuit? +

Type C is commonly used for general motor and mixed loads with moderate inrush current (many small to medium motors, general mixed commercial/industrial circuits), while Type D is used for loads with very high inrush current — large motors, transformers, and similar high-inrush equipment — that would nuisance-trip a Type B or even Type C MCB during normal starting.

Can I use a higher curve type than necessary just to be safe? +

Not without a trade-off — a higher curve type (C or D) tolerates more inrush current without instantaneous tripping, but this also means it takes a larger fault current to trigger instantaneous protection, which can affect fault clearing speed and protection coordination with other devices. Match the curve type to your actual load's real inrush characteristics rather than defaulting to the highest option "to be safe."

Does MCB rating alone provide motor overload protection? +

Not adequately on its own for most motor applications — similar to fuses, an MCB sized to ride through motor starting current is generally too insensitive to catch a moderate, sustained overload condition. Motor circuits typically need a separate overload relay (or a motor circuit breaker/protector specifically designed with both magnetic and adjustable thermal overload protection) for genuine running overload protection.

What is the difference between an MCB and an MCCB? +

MCBs (Miniature Circuit Breakers) are generally used for lower current ratings (commonly up to 63-125A depending on the standard and manufacturer) in residential, commercial, and light industrial applications, while MCCBs (Molded Case Circuit Breakers) handle higher current ratings and often offer more adjustable trip settings and higher fault interrupting capacity, more common in industrial and larger commercial installations — use the appropriate device type sized for your circuit's actual current and fault current requirements.

Should MCB rating exceed the protected cable's ampacity? +

For general circuits, no — the MCB should generally be rated at or below the cable's safe ampacity, so the MCB trips before the cable is damaged by sustained overcurrent. This is the same general principle that applies to fuse-and-cable coordination, and any exception (like specific motor circuit allowances) should be verified against the applicable code rather than assumed.

How do I know the actual inrush current of my specific load to pick the right curve type? +

Check the equipment manufacturer's datasheet for starting/inrush current specifications where available — for motors, this is often expressed as a multiple of full load current or a locked-rotor current rating; for transformers, inrush current (which can be considerably higher and longer-lasting than motor starting current) is sometimes specified separately. Where exact data isn't available, general guidelines by load category (as in the reference table on this page) provide a reasonable starting point, refined through field testing if nuisance tripping occurs.

What is the difference between a Type B and a Type C MCB? +

Only the instantaneous trip band. A Type B trips instantly between three and five times its rated current; a Type C between five and ten times. Both have the same thermal characteristic, so a 16 A of either carries 16 A indefinitely and trips on a sustained overload the same way. Type B suits resistive loads with no inrush — lighting and heating. Type C tolerates the brief surge of small motors, transformers and LED driver banks. Raising the curve to stop nuisance tripping also raises the current needed for an instantaneous trip, so the earth fault loop impedance should be re-checked when you do.

What is a Type K and a Type Z MCB used for? +

Type K trips instantly at roughly eight to twelve times rated current, sitting between C and D, and is used on industrial motor and transformer circuits where a tighter band than Type D is wanted. Type Z trips at two to three times and protects semiconductor and measuring circuits that cannot tolerate much overcurrent at all. Both come from industrial breakers built to IEC 60947-2 rather than the IEC 60898-1 household set that defines B, C and D, so check availability with your supplier before specifying one.

What is the difference between a TPN and a 4-pole MCB? +

A TPN breaker has three protected poles plus a neutral on a solid link — the neutral is brought into the device but is not disconnected when it opens. A 4-pole breaker has a genuine fourth switched pole and breaks the neutral with the phases. If the reason for wanting the neutral in the breaker is isolation, a TPN will not provide it. Lists that describe the two as the same thing are the usual source of this mistake.

Does the number of poles change the MCB rating or trip curve? +

No. A 16 A Type C has the same thermal characteristic and the same instantaneous trip band whether it is single-pole or four-pole. Rating comes from the load current, the curve comes from the inrush, and the pole count comes from which conductors the installation needs to isolate — three independent choices that happen to be combined in one product code.
